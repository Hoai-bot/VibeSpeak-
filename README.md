# 🌆 VIBESPEAK: Survive the Neon City

**VibeSpeak** không chỉ là một ứng dụng học ngôn ngữ thông thường, nó là một đấu trường sinh tồn. Trong thế giới Dystopian tàn khốc, tiếng Anh chuẩn xác, tự nhiên và trôi chảy chính là vũ khí duy nhất để bạn sống sót, kiếm EXP và vươn lên đỉnh cao.

## 🚇 Hệ Thống 4 Trạm Tàu Điện
* **Trạm 1: Tân Binh (Terminal):** Luyện tập nhại âm (Shadowing) 1:1 với Giám khảo AI khắt khe.
* **Trạm 2: Đấu Trường Tất Tay (Arena):** Đặt cược EXP, ghép cặp Real-time và thi đấu trực tiếp với các Runner khác.
* **Trạm 3: Bóng Ma (Shadow Boss):** Thách đấu kỷ lục ghi âm của kẻ thống trị (Top 1) tuần trước.
* **Trạm 4: Trạm Cứu Trợ (Oasis):** Nơi an toàn duy nhất để nhận trợ cấp và nghe Radio Lofi thư giãn.

## 🛠️ Công Nghệ Lõi (Tech Stack)
* **Frontend:** React Native (Expo) mang hơi hướng UI Neon Cyberpunk (#39FF14, #FF007F, #00FFFF).
* **Backend:** Supabase (PostgreSQL, Realtime WebSockets cho Matchmaking).
* **AI Engine:** Groq API xử lý Speech-to-Text và chấm điểm ngữ pháp/độ tự nhiên siêu tốc.
